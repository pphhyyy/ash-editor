# ASH 1.0

此 release 使用 build18 源码作为代码基线（包含 Dock 退出崩溃修复）；应用显示版本统一为 1.0，build 号为 1。

主窗口的标题和操作栏现在使用隐藏标题栏预留的顶部区域；纯净模式保留独立的 5px 窗口拖动区，标签栏右移避开 macOS 窗口控制按钮。拖动标签时，紫色竖线显示实际插入缝，包括相邻标签之间和标签栏末尾。聊天框模式的拖动条缩窄并根据当前文字色使用轻微色差，适配紫雾、纸感、夜色三种主题。

- `source/`：对应本 app 的源码和本地 Swift 依赖。
- `ASH-1.0.app`：由该源码编译的 arm64 macOS 应用。
